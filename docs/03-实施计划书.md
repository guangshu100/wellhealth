## 三、技术实现方案

### 3.1 Agent系统架构

```python
# Agent定义格式 (参考agency-agents)
# 文件: agents/{type}/metadata.yaml
name: "糖尿病专科Agent"
description: "专注于糖尿病患者的健康咨询"
role: "内分泌科医生助手"
specialty: ["糖尿病", "糖尿病肾病", "糖尿病视网膜病变"]
personality: "专业、耐心、鼓励型"
system_prompt: file: "agents/{type}/prompt.md"

# Agent执行流程
class AgentExecutor:
    def execute(self, user_input: str, context: dict):
        # 1. 意图识别
        intent = self.classify_intent(user_input)
        
        # 2. 知识检索
        knowledge = self.retrieve_knowledge(intent)
        
        # 3. 生成回复
        response = self.generate(intent, knowledge, context)
        
        # 4. 安全检查
        safe_response = self.safety_check(response)
        
        return safe_response
```

### 3.2 RAG系统架构

```python
# RAG检索流程
class MedicalRAG:
    def __init__(self):
        self.vector_store = QdrantClient()
        self.graph_store = Neo4jClient()
        self.llm = LLMClient()
    
    def retrieve(self, query: str, patient_context: dict):
        # 1. 向量检索
        vector_results = self.vector_store.search(query)
        
        # 2. 图谱检索
        graph_results = self.graph_store.query(query)
        
        # 3. 重排序
        reranked = self.rerank(vector_results, graph_results)
        
        # 4. 生成回答
        response = self.llm.generate(query, reranked, patient_context)
        
        return response
```

### 3.3 安全评估架构

```python
# 安全红线检查
class SafetyChecker:
    RED_LINES = [
        "禁止给出诊断结论",
        "禁止推荐具体药物剂量",
        "禁止替代专业医疗建议",
        "紧急情况必须建议就医"
    ]
    
    def check(self, response: str) -> SafetyResult:
        for line in self.RED_LINES:
            if self.violates(response, line):
                return SafetyResult(safe=False, reason=line)
        return SafetyResult(safe=True)
    
# 红队测试
class RedTeamTester:
    def run_tests(self, agent: Agent) -> EvalReport:
        results = []
        for case in self.test_cases:
            response = agent.execute(case.probe)
            passed = self.evaluate(response, case.expected)
            results.append(TestResult(case, response, passed))
        return EvalReport(results)
```
