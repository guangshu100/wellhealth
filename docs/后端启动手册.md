# 康伴(WellHealth) 后端项目启动手册

## 一、环境要求

### 1.1 基础环境
- **操作系统**: Windows 10/11 或 Linux/macOS
- **Python**: 3.10 或更高版本
- **Node.js**: 18.x 或更高版本（前端开发需要）

### 1.2 依赖服务
| 服务 | 版本要求 | 用途 | 端口 |
|------|----------|------|------|
| MySQL | 8.0+ | 主数据库 | 3306 |
| Redis | 6.0+ | 缓存/会话 | 6379 |
| Neo4j | 5.x | 知识图谱 | 7687 |
| Qdrant | 1.x | 向量检索 | 6333 |

> **注意**: 如果仅需启动后端服务进行基础开发测试，可以先不启动 Neo4j 和 Qdrant，但部分功能（如知识图谱检索）将不可用。

## 二、依赖服务安装

### 2.1 MySQL 安装

#### Windows
1. 下载 MySQL Installer: https://dev.mysql.com/downloads/installer/
2. 选择 `MySQL Server 8.0` 安装
3. 配置root密码: `wellhealth123`
4. 创建数据库:
```sql
CREATE DATABASE wellhealth CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### Linux (Ubuntu)
```bash
sudo apt update
sudo apt install mysql-server
sudo systemctl start mysql
sudo mysql -u root -e "CREATE DATABASE wellhealth CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
sudo mysql -u root -e "CREATE USER 'wellhealth'@'localhost' IDENTIFIED BY 'wellhealth123';"
sudo mysql -u root -e "GRANT ALL PRIVILEGES ON wellhealth.* TO 'wellhealth'@'localhost';"
sudo mysql -u root -e "FLUSH PRIVILEGES;"
```

#### macOS
```bash
brew install mysql
brew services start mysql
mysql -u root -e "CREATE DATABASE wellhealth CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

### 2.2 Redis 安装

#### Windows
推荐使用 [Memurai](https://www.memurai.com/) 或 [WSL2](https://docs.microsoft.com/zh-cn/windows/wsl/) 运行Redis。

```bash
# 使用 WSL2
wsl --install
# 在 WSL2 中
sudo apt install redis-server
sudo systemctl start redis
```

#### Linux/macOS
```bash
# Linux
sudo apt install redis-server
sudo systemctl start redis

# macOS
brew install redis
brew services start redis
```

### 2.3 Neo4j 安装（可选）

#### Windows/Linux/macOS
```bash
# 使用 Docker（推荐）
docker run -d \
  --name neo4j \
  -p 7474:7474 \
  -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/password \
  neo4j:5
```

访问 http://localhost:7474 验证，初始账号: `neo4j` / `password`

### 2.4 Qdrant 安装（可选）

```bash
# 使用 Docker（推荐）
docker run -d \
  --name qdrant \
  -p 6333:6333 \
  -p 6334:6334 \
  qdrant/qdrant
```

## 三、项目初始化

### 3.1 克隆项目
```bash
git clone <项目仓库地址>
cd wellhealth
```

### 3.2 创建虚拟环境

#### Windows (PowerShell)
```powershell
# 安装 python3-venv（如果需要）
# python -m venv venv

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
.\venv\Scripts\Activate.ps1
```

#### Linux/macOS
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3.3 安装依赖

```bash
# 升级 pip
pip install --upgrade pip

# 安装项目依赖
cd backend
pip install -e .

# 或者使用 pyproject.toml
pip install poetry
poetry install
```

## 四、配置说明

### 4.1 复制环境配置文件
```bash
cd backend
copy .env.example .env
```

### 4.2 配置文件说明 (.env)

```env
# ==================== 应用配置 ====================
APP_NAME=WellHealth
APP_VERSION=1.0.0
DEBUG=true

# ==================== 服务器配置 ====================
HOST=0.0.0.0
PORT=8000

# ==================== MySQL 数据库配置 ====================
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=wellhealth
MYSQL_PASSWORD=wellhealth123
MYSQL_DATABASE=wellhealth

# ==================== Redis 配置 ====================
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=

# ==================== Neo4j 知识图谱（可选）================
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=password

# ==================== Qdrant 向量库（可选）================
QDRANT_HOST=localhost
QDRANT_PORT=6333
QDRANT_API_KEY=

# ==================== LLM 大模型配置 ====================
# 可选: openai / anthropic / dashscope / ollama / siliconflow
LLM_PROVIDER=openai

# OpenAI 配置
OPENAI_API_KEY=your-openai-api-key
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini

# Anthropic 配置（可选）
ANTHROPIC_API_KEY=
ANTHROPIC_MODEL=claude-3-5-sonnet-20241022

# 阿里云通义配置（可选）
DASHSCOPE_API_KEY=
DASHSCOPE_MODEL=qwen-plus

# 硅基流动配置（可选）
SILICONFLOW_API_KEY=
SILICONFLOW_BASE_URL=https://api.siliconflow.cn/v1
SILICONFLOW_MODEL=Qwen/Qwen2.5-7B-Instruct

# Ollama 本地模型（可选）
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3
OLLAMA_TIMEOUT=120

# ==================== 安全配置 ====================
SECRET_KEY=wellhealth-secret-key-change-in-production
```

### 4.3 修改 LLM 配置

项目支持多种大模型供应商，请根据实际情况修改:

## 八、常见问题

### 8.1 数据库连接失败
- 检查 MySQL 服务是否启动
- 验证用户名密码是否正确
- 确认数据库已创建

### 8.2 Redis 连接失败
- 检查 Redis 服务是否启动
- 验证端口 6379 是否被占用

### 8.3 LLM API 调用失败
- 确认 API Key 正确配置
- 检查网络连接
- 确认模型名称正确

### 8.4 Neo4j/Qdrant 连接失败
- 这些服务为可选依赖
- 如不需要知识图谱/向量检索功能，可不启动
