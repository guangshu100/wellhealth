# TabBar Icons

需要放置以下图标文件（建议尺寸：81x81px）：

## 未选中状态
- `home.png` - 首页
- `health.png` - 健康
- `chat.png` - 咨询
- `medication.png` - 用药
- `profile.png` - 我的

## 选中状态
- `home-active.png` - 首页（选中）
- `health-active.png` - 健康（选中）
- `chat-active.png` - 咨询（选中）
- `medication-active.png` - 用药（选中）
- `profile-active.png` - 我的（选中）

## 图标要求
- 尺寸：建议 81x81 像素
- 格式：PNG
- 风格：扁平化、简洁
- 颜色：未选中灰色(#999999)，选中蓝色(#409EFF)

## 注意事项
图标需要自行准备或设计，可以使用以下工具生成：
- iconfont: https://www.iconfont.cn/
- iconpark: https://iconpark.oceanengine.com/
